Code review is the process of reviewing the code changes by the author of the change, and it often required the reviwer to decide what is the next step after the review, wheather to comment, make suggestion, approve or reject. Formal configuration audit (FCA/PCA from the NASA reading) is the audit process where it does not only audit the code but the overall project's performance, and also the version of the files and the overal baseline. The pull request I did just now is just code review which is part of the process of Functional Configuration Audit.
