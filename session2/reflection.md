Q1 How do Issues and pull requests together support change control?<br>
It started with the Issues which address the changes wanted to make and it is a request to apply those changes. After that, the pull request can be associate with the issue whereby the pull request is like the implementation of the changes wanted from the Issues mentioned. After the pull request is reviewed and merged to the main codebase, the issue will also claose together with the pull request.
